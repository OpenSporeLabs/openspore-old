# Handoffs

Dated, verified continuation records. One file per completed task:
`YYYY-MM-DD-<task-slug>.md`. Each states objective/scope, what was discovered (with
source links), what changed and why, tests/verification **actually run**, decisions
and rejected alternatives, unresolved issues, relevant files/symbols/commands, and
a copy-pasteable continuation prompt. A handoff records work that was finished and
verified — it never substitutes for finishing it.
