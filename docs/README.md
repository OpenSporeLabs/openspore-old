# OpenSpore documentation index

Authoritative project record. `AGENTS.md` is the compact rules router; this is the
map of the deeper documents. Start with the status set, then the area you are
touching. Each document states its own owner/purpose/status/date.

## Status & boundaries (read first)
- `STATE.md` — current verified state.
- `MIGRATION.md` — C++/Python ↔ Rust subsystem classification.
- `replacement-status.json` — per-subsystem replacement status + evidence.
- `BOUNDARIES.md` — compatibility/replacement seams; the `spore-recomp` boundary.
- `VALIDATION.md` — what the Rust half is actually checked against.
- `RUST-ENGINE.md`, `VERTICAL-SLICE.md` — the engine and the end-to-end slice.
